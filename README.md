# BU_Project
본 프로젝트는 백석대학교의 주요 건물과 캠퍼스 환경을 3D로 제작한 뒤, Unity 엔진을 활용해 가상 캠퍼스 공간을 구현하는 것을 목표로 한다. 사용자는 캐릭터(또는 1인칭 시점)로 가상 공간에 접속하여 캠퍼스를 직접 걸어 다니듯 이동하고 탐색할 수 있으며, 건물별 위치와 특징을 시각적으로 이해할 수 있다. 단순한 이미지나 영상이 아닌 ‘참여형 체험’ 형태로 구성하여, 실제 방문이 어려운 상황에서도 캠퍼스 분위기와 동선을 자연스럽게 경험할 수 있도록 한다. 또한 건물 정보 안내, 추천 투어 동선, 행사/시설 소개 등 확장 기능을 통해 학교 안내 및 홍보 콘텐츠로 활용 가능성을 높인다.
